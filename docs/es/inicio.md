# Megumi Kura — Inicio

Sistema de código abierto para iglesias y comunidades que gestionan donaciones
de alimentos, stock, canastas básicas y promesas de contribución.

## Ideas clave

- El stock se calcula a partir de movimientos
- Las promesas no son stock real
- La API pública no requiere autenticación
- Las operaciones administrativas sí
