# Security Policy

## Supported versions

Security fixes are accepted for the latest `main` branch of Megumi Kura.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via GitHub Security Advisories for this repository, or contact
the maintainers listed in the repository profile.

Include:

- A description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

## Development credentials

The development seed creates a local admin user with a well-known password.
That password is for **local development only** and must be changed before any
shared or production deployment. Never commit real credentials.
